# Public Company ESG Ratings — Environmental, Social & Governance Scores

## Dataset Profile
- **File**: `data.csv`
- **Size**: 42 KB (722 companies)
- **Source**: Finnhub
- **License**: CC-BY-NC-SA-4.0

## Schema (21 columns)
| Column | Description |
|--------|-------------|
| `ticker` | Stock symbol |
| `name` | Company name |
| `currency` | Reporting currency |
| `exchange` | Listing exchange |
| `industry` | Industry classification |
| `environment_grade` | A–F scale |
| `environment_level` | High/Medium/Low |
| `social_grade` | A–F scale |
| `social_level` | High/Medium/Low |
| `governance_grade` | A–F scale |
| `governance_level` | High/Medium/Low |
| `environment_score` | Numeric score |
| `social_score` | Numeric score |
| (plus governance_score and overall metrics) |

## Key Findings
- **722 public companies** with letter-grade ESG ratings
- Environment, Social, and Governance scored separately
- Example: Disney (Environment: A/High, Social: BB/Medium)
- Includes direct links to company websites and logos
- Numeric scores enable quantitative analysis

## Campaign Value
1. **Governance grade** — Direct proxy for transparency and accountability
2. **Sector comparison** — Identify how financial sector ESG compares
3. **Greenwashing detection** — Compare ESG claims with actual behavior
4. **Cross-reference with integrity scores** — Validate ESG ratings against integrity data
5. **Campaign targeting** — Focus on companies with poor governance ratings

## Analysis Potential
- Correlate governance grade with insider trading patterns
- Compare ESG ratings with integrity scores for discrepancies
- Identify companies with high environmental but low governance scores
- Build sector-specific governance benchmarks
