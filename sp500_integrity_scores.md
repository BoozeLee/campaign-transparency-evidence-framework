# S&P 500 Integrity Scores — Multi-Dimensional Corporate Ethics

## Dataset Profile
- **File**: `sp500_integrity_scores.csv`
- **Size**: 14 KB (503 companies)
- **Source**: Corporate integrity assessment
- **License**: CC-BY-NC-SA-4.0

## Schema (16 columns)
| Column | Description |
|--------|-------------|
| `ticker` | Stock symbol |
| `company_name` | Legal name |
| `exchange` | Listing exchange |
| `sector` | Industry classification |
| `overall_rating` | Mixed, Good, Poor, etc. |
| `planet_friendly_business` | Environmental score (−100 to +100) |
| `honest_fair_business` | Transparency/ethics score |
| `no_war_no_weapons` | Weapons involvement score |
| `fair_pay_worker_respect` | Labor practices score |
| `better_health_for_all` | Health impact score |
| `safe_smart_tech` | Technology ethics score |
| `kind_to_animals` | Animal welfare score |
| `respect_cultures_communities` | Community impact score |
| `fair_money_economic_opportunity` | Economic fairness score |
| `fair_trade_ethical_sourcing` | Supply chain ethics score |

## Key Findings
- **All 503 S&P 500 companies** scored across 11 integrity dimensions
- Scores range from −100 to +100 on each dimension
- Most companies rated "Mixed" overall
- Apple: Planet +40, Honest −20, Pay −30
- Sector-level patterns visible

## Campaign Value
1. **Honest/fair business score** — Direct proxy for transparency behavior
2. **Fair money score** — Relevance to financial sector ethics
3. **Sector benchmarking** — Compare financial sector integrity to other sectors
4. **Cross-reference with filings** — Link integrity scores to actual SEC filing behavior
5. **Campaign scoring** — Use methodology to score ETF custodians
