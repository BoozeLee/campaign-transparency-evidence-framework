# Journalist-Ready Evidence Packaging

## Purpose
Investigative journalists cannot process raw evidence repositories. They need concise, verified, narrative-ready packages. This template ensures every package is publication-safe.

## Package Structure
Each journalist package contains exactly four components:

### 1. One-Page Briefing Memo
```
CONFIDENTIAL — INVESTIGATIVE BRIEFING
─────────────────────────────────────
To:             {journalist name}
From:           {campaign contact}
Date:           {YYYY-MM-DD}
Classification: Tier {B or C only — NEVER Tier A}

SUBJECT: {one-line headline}

KEY FINDING (2 sentences):
{what we found and why it matters}

SUPPORTING EVIDENCE:
- {finding 1} — Source: {type}, Confidence: {1-5}
- {finding 2} — Source: {type}, Confidence: {1-5}
- {finding 3} — Source: {type}, Confidence: {1-5}

WHY THIS IS SIGNIFICANT:
{regulatory significance / public interest / novelty}

CONTACT FOR QUESTIONS:
{name, Signal number, encrypted email}
```

### 2. Annotated Timeline
```
TIMELINE: {Institution / Issue Name}
────────────────────────────────────
Date         Event                          Source            Confidence
{YYYY-MM-DD} {description of event}         {source ref}      {1-5}
{YYYY-MM-DD} {description of event}         {source ref}      {1-5}
...
```

### 3. Source Confidence Map
```
SOURCE MAP
──────────
Document A (Tier A, Conf 5): SEC enforcement order against {entity}
Document B (Tier B, Conf 3): Internal email from whistleblower (corroborated by Document C)
Document C (Tier B, Conf 3): Regulatory filing with matching data
Document D (Tier C, Conf 2): Public statement by former employee
```

### 4. Entity Relationship Chart (Text Format)
```
ENTITY RELATIONSHIPS
────────────────────
{Parent Company}
    ├── Subsidiary A (jurisdiction, role)
    ├── Subsidiary B (jurisdiction, role)
    │       └── PSC: {name} (nationality, control type)
    └── Subsidiary C (jurisdiction, role)
            └── Custodian: {bank name}

{Regulatory Body} → Enforcement action against {entity} on {date}
```

## Rules for Journalist Briefings

1. **Never share Tier A evidence** before regulatory filing
2. **Clearly mark confidence scores** on every document
3. **Never speculate** — state only what evidence supports
4. **Provide publication-safe summaries** — include redaction log
5. **Offer independent verification paths** — sources journalist can check
6. **Set embargo terms** in writing

## Embargo Template
```
EMBARGO AGREEMENT
─────────────────
These materials are shared on embargo until {date/time}.
The embargo covers: {scope of materials}
Breach consequences: {e.g., future access terminated}

Signed:
{journalist}              {campaign representative}
{date}                    {date}
```
