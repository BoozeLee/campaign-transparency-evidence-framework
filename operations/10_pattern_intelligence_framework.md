# Historical Pattern Intelligence Framework

## Purpose
The strongest strategic asset is not individual cases — it is the detection of systemic patterns across institutions, jurisdictions, and time. This framework enables pattern recognition at scale.

## Pattern Categories

### Enforcement Blind Spots
```
PATTERN: Enforcement Blind Spot
────────────────────────────────
Description:  Types of violation that regulators consistently miss
Evidence:     {cases where similar violations went unactioned}
Hypothesis:   {why — resource gap, mandate gap, expertise gap}
Campaign Use: {target this gap as advocacy opportunity}
```

### Institutional Behavioral Patterns
```
PATTERN: Institutional Playbook
───────────────────────────────
Institution:  {name}
Sequence:
  1. {first move — e.g., delayed response}
  2. {second move — e.g., partial disclosure}
  3. {third move — e.g., procedural deflection}
Frequency:    {observed in N of M cases}
Predictive:   {next time, expect this sequence}
```

### Cross-Border Coordination Failures
```
PATTERN: Regulatory Coordination Failure
─────────────────────────────────────────
Home Regulator:    {regulator A}
Host Regulator:    {regulator B}
Known Gap:         {what falls between them}
Example Cases:     {cases where neither acted}
Recommendation:    {how to exploit this gap}
```

### Disclosure Asymmetries
```
PATTERN: Systematic Disclosure Asymmetry
─────────────────────────────────────────
Disclosure Type:  {e.g., custody arrangements}
Institutions:     {list of institutions with same pattern}
Common Element:   {what they all omit}
Regulatory Rule:  {what rule arguably requires disclosure}
```

### Regulatory Arbitrage
```
PATTERN: Regulatory Arbitrage
─────────────────────────────
Structure:    {e.g., booking custody in jurisdiction X while operating in Y}
Used by:      {institutions using this structure}
Regulatory Gap: {why neither regulator catches it}
Evidence:     {supporting evidence IDs}
```

## Pattern Detection Methodology

### Quantitative (Data-Driven)
- Time-series analysis of filing patterns
- Network analysis of entity relationships
- Anomaly detection in reported data
- Correlation analysis across datasets

### Qualitative (Investigator-Driven)
- Read 8-K filings for pattern language
- Compare institutional responses to same query
- Track regulatory enforcement publication trends
- Whistleblower testimony pattern extraction

## Strategic Value
Pattern intelligence transforms the campaign from:
- "Here are N individual cases of opacity" (reactive, case-by-case)
- To: "Here is a systematic pattern of behavior across M institutions over T years" (proactive, structural)

The latter is far more compelling to regulators, journalists, and the public.
