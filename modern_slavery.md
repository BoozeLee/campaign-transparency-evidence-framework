# Global Slavery Index — Modern Slavery & Forced Labor Intelligence

## Dataset Profile
- **File**: `Global_Slavery_Index_2023.csv`
- **Size**: 6 KB (179 countries)
- **Period**: 2023
- **Source**: Walk Free Foundation
- **License**: Apache 2.0

## Schema
| Column | Description |
|--------|-------------|
| `Country` | Country name |
| `Population` | National population |
| `Region` | Geographic region |
| `Estimated prevalence of modern slavery per 1,000 population` | Prevalence rate |
| `Estimated number of people in modern slavery` | Absolute count |

## Key Findings
- **179 countries** with modern slavery estimates
- Ranges from <1 to 50+ per 1,000 population
- Correlates with governance quality and corruption
