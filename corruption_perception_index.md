# Global Corruption Perception Index — Country-Level Transparency Benchmarking

## Dataset Profile
- **File**: `Corruption_Perception_Data.csv`
- **Size**: 723 KB (~3,000 records)
- **Period**: Multi-year (2006–2024)
- **Source**: Compiled from Transparency International and related indices
- **License**: MIT

## Schema (33 columns)
| Column | Description |
|--------|-------------|
| `Country` | Country name |
| `Year` | Observation year |
| `CPI_Score` | Corruption Perceptions Index (0–100) |
| `Rank` | Global rank |
| `Region` | Geographic region |
| `Public_Sector_Corruption` | Sub-index for public sector |
| `Judicial_Corruption` | Judicial integrity score |
| `Police_Corruption` | Law enforcement integrity |
| `Executive_Branch_Corruption` | Executive corruption score |
| `Legislative_Corruption` | Legislative integrity |
| `Bribery_Index` | Frequency of bribery |
| Additional | Business, Health, Education, Media corruption subscores |

## Key Findings
- Comprehensive corruption metrics across **countries and years**
- Multiple sub-indices for **sector-specific corruption analysis**
- Enables cross-country and cross-temporal comparison
- Links regulatory quality to corruption levels

## Campaign Value
1. **Jurisdictional risk assessment** — Score countries by corruption for targeting
2. **Regulatory quality proxy** — CPI scores correlate with regulatory enforcement quality
3. **Cross-reference with tax havens** — Compare CPI of tax haven jurisdictions
4. **Benchmarking** — Use CPI to benchmark transparency campaign targets
5. **Historical trends** — Track corruption trends over time in target jurisdictions

## Analysis Potential
- Correlate CPI scores with FATF/OFAC blacklist status
- Map ETF custody chains to countries by CPI score
- Build jurisdiction risk scoring model combining CPI + regulatory enforcement data
- Identify countries with improving/worsening corruption trends relevant to campaign
