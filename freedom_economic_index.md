# Economic Freedom Index — Country-Level Institutional Quality

## Dataset Profile
- **File**: `freedomIndexUpdated2024.csv`
- **Size**: 12 KB (184 countries)
- **Period**: Updated 2024
- **Source**: Heritage Foundation
- **License**: ODbL-1.0

## Schema (15 columns)
| Column | Description |
|--------|-------------|
| `Country` | Country name |
| `Region` | Geographic region |
| `Overall Score` | Composite freedom score (0–100) |
| `Property Rights` | Property rights protection |
| `Government Integrity` | Government integrity score |
| `Judicial Effectiveness` | Judicial system quality |
| `Tax Burden` | Tax burden score |
| `Government Spending` | Government expenditure |
| `Fiscal Health` | Fiscal sustainability |
| `Business Freedom` | Ease of doing business |
| `Labor Freedom` | Labor market flexibility |
| `Monetary Freedom` | Monetary stability |
| `Trade Freedom` | Trade policy openness |
| `Investment Freedom` | Capital flow openness |
| `Financial Freedom` | Banking/finance openness |

## Key Findings
- **184 countries** ranked by economic freedom
- Top: Singapore (83.5), Switzerland (83.0), Ireland (82.6)
- 12 sub-indices enable granular institutional quality analysis
- Government Integrity and Judicial Effectiveness directly relevant to transparency campaigns

## Campaign Value
1. **Institutional quality benchmarking** — Score countries by transparency-related sub-indices
2. **Government Integrity** — Direct proxy for regulatory transparency
3. **Judicial Effectiveness** — Indicator of enforcement quality
4. **Financial Freedom** — Relevance to custody and capital markets
5. **Investment Freedom** — Capital flow transparency implications

## Analysis Potential
- Correlate economic freedom with CPI scores
- Map ETF registration jurisdictions to freedom scores
