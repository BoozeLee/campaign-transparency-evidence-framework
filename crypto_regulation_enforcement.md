# Cryptocurrency Regulations Enforcement — Global Regulatory Action Database

## Dataset Profile
- **File**: `Cryptocurrencies Regulations Enforcement.csv`
- **Size**: 4 KB (63 records)
- **Source**: Compiled from regulatory announcements
- **License**: CC0-1.0

## Schema (20 columns)
| Column | Description |
|--------|-------------|
| `Case ID` | Unique identifier |
| `Date of Action` | Enforcement date |
| `Regulatory Body or Bodies` | SEC, CFTC, FCA, etc. |
| `Entity/Individual` | Target name |
| `Category of Enforcement` | Written Agreement, Cease & Desist, Fine |
| `Description of Violation` | Nature of violation |
| `Amount of Fine` | Penalty amount |
| `Outcome` | Resolution |
| `Relevant Regulations Violated` | Legal basis |
| `Links to Official Documents` | Source URLs |

## Key Findings
- **63 enforcement actions** catalogued
- Regulatory bodies: SEC, Federal Reserve, and others
- Includes Written Agreements, Cease & Desist Orders
- Direct links to official press releases for verification
- Covers actions from 2024
