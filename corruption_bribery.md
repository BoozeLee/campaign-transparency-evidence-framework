# Corruption & Bribery Incident Database — Grassroots Transparency Intelligence

## Dataset Profile
- **File**: `data.csv`
- **Size**: 103 KB (3,476 records)
- **Source**: Citizen-reported bribery incidents (India-focused)
- **License**: CC0-1.0

## Schema
| Column | Description |
|--------|-------------|
| `Title` | Description of the incident |
| `Date` | Date of occurrence |
| `Location` | City, State |
| `Department` | Government/service department involved |
| `Views` | Public views/engagement |
| `Amount(INR)` | Bribe amount in Indian Rupees |

## Key Findings
- **3,476 citizen-reported bribery incidents**
- Covers departments: Births, Vehicle Insurance, Driving/Transport, Police, Land Registry, etc.
- Amounts range from small (100 INR) to significant
- Crowdsourced intelligence model demonstrates transparency-by-the-public methodology

## Campaign Value
1. **Grassroots evidence methodology** — Model for citizen-driven transparency campaigns
2. **Department-level granularity** — Shows how bureaucratic opacity enables corruption
3. **Public engagement metrics** — Views data shows which issues resonate
4. **Scale of corruption** — Even small bribes document systematic institutional failure

## Analysis Potential
- Apply crowdsourcing methodology to ETF custody transparency
- Build reporting platform for financial transparency violations
- Analyze institutional patterns across departments
- Correlate bribery incidents with regulatory enforcement gaps
